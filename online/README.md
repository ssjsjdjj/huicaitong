## 导入恢复与加载

政策恢复逐份进行，单条失败不阻断其他有效记录。格式错误、编号冲突和版本不兼容会显示原因；原始缓存不会自动清除。可下载原始记录和当前可用政策，或在成功保存恢复备份后选择仅保留可用政策。存储已满时保留原记录，并提示新导入仅在当前标签页使用。知识库页提供恢复备份下载入口。

浏览器前进、后退可在功能页之间切换；手机导航完整显示七个入口。清空资料后再返回报告页会显示空状态，不继续展示旧报告。

首屏资料由独立小包提供，页面可先浏览、填写和查看历史记录，Python 引擎后台准备。核验逻辑与 PDF 阅读器拆成按内容命名的两个包；PDF 仅首次读取时加载。浏览器支持时，CacheStorage 只缓存列入清单的版本化静态组件，不缓存申请表、材料或评测输入。加载失败可重试，已填写内容保留。首次仍需下载引擎，不承诺离线启动或固定加载秒数。

## 人工评测流程

1. 在「人工复核」阅读标注说明。内置 36 条只作开发练习，不能冻结为独立测试集。
2. 可新增合成或脱敏案例，记录来源及既往开发使用情况。新增案例不预填结论；只接受已有申请字段，不接受身份标识字段。
3. 核对原文，填写结论、引用、缺失字段、准备清单、解释和复核者标识，明确确认后保存。修改已确认记录会退回待复核。暂存在当前标签页，长期保留需下载草稿。
   恢复文件遇到已有填写的同编号案例时，先提示冲突，不自动覆盖。明确选择替换时先保存完整恢复前备份；存储不足则停止。备份可在工作台下载并恢复。筛选为空时不提供其他案例的编辑表单。
4. 冻结当前筛选范围内的已确认记录。文件含政策快照和 SHA-256，可按原快照复现；指纹只检测文件变化，不认证标注正确性。
5. 测试用途会拦截内置练习、与已有开发/历史检查记录人物字段完全重复的案例，以及未声明使用情况的案例。近重复和外部训练历史仍需人工负责，不能据此声称跨政策泛化。
6. 下载不含人工答案的预测输入与空模板，在独立模型环境生成真实输出，再导入文件或粘贴 JSON / JSONL。页面不运行或伪造模型预测。
7. 只在同一冻结集内对照结果。缺失预测计错；重复或未知编号、错误指纹会被拒绝。显示类别指标和逐条错误，可备份全部标签页对照。引用 F1 只比较编号，不验证解释语义。
   新冻结集应先下载再刷新或切换；未下载时提供关闭提示并阻止被另一份集替换。下载当前对照后，已备份记录不再产生多余的未保存提示。

软件测试夹具不属于人工政策基准，默认草稿仍未人工确认。本轮没有新增真实人工标注或重新训练模型。

### 使用现有本地模型生成预测

从网站下载「预测输入与空模板」，在本机启动实际模型服务后运行：

```powershell
python scripts/predict-frozen.py --input 下载的预测模板.json --model 你的实际模型名称 --base-url http://127.0.0.1:8766/v1 --output 新的预测文件.json
```

可先加 `--dry-run` 检查模板，不发出网络请求。脚本仅连接本机，实际运行才调用模型；原始返回按案例保存，失败调用明确列出，不生成替代答案，不覆盖已有文件。将输出文件导回网页即可按指纹对齐冻结集。本入口使用完整政策条款，比较 Base / SFT / GRPO 时须固定同一输入及生成参数，不直接沿用旧表格数字。
