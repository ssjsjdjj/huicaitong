# v0.3 核验流程与材料工作台

本轮增加证据链路、材料字段确认与人工复核工具，没有训练新模型，没有改写旧模型的测试结果，也没有新增或自动确认官方政策的现行效力。

## 先检索，再补齐必要依据

政策匹配页可填写重点核对的问题。默认在所选事项、参考日期范围内做 BM25 检索，取前三条相关条款，再补齐已录入适用范围、规则、准备清单所引用的条款。

必要证据缺失时停止模型核验；模型只能引用实际提供的证据编号。模型输入不包含规则结论或规则逐项判断。模型返回后再独立运行原有一致性对照。界面可查看检索命中、补齐依据、参考日期与来源发布日期；导出记录同时包含上下文和政策快照散列。

本库只有三项初筛事项、两个主要来源，生活补贴首笔的七条证据均与已录入规则或清单关联，因此当前经常会补齐为全部条款。**这里没有宣称减少上下文长度或提升准确率。** 这不是向量检索、重排模型或经过 GRPO 训练的自主检索策略。上下文完整只指已编码条件，不等于原政策完整或现行有效。

旧版“整份事项条款”模式继续保留。离线预测默认也保留旧提示；可显式选择新流程：

```powershell
python -m training.predict --data data/generated/validation_grpo.jsonl --model 本地基础模型目录 --adapter checkpoints/grpo --evidence-mode retrieval --output training-runs/retrieval-development.jsonl
```

应另行评测新提示，不能沿用旧固定提示的 61/92、22/48 作为新流程准确率。本轮只做单案例真实模型联调：检索 3 条、补齐 4 条；模型仍错误地输出可申请首笔，规则对照返回需复核。记录见 `training-runs/v3-retrieval-demo.json`，它不是准确率基准。

## 材料核验：提取、确认、再初筛

1. 上传文字 PDF 或 TXT，或选择三份合成材料样例。
2. 查看候选字段、原文页码／行号、与表单值的冲突。
3. 逐项勾选已经核对的字段，点击填入表单。
4. 重新初筛，报告保留仍与当前字段及计算日期一致的材料确认记录。

默认不勾选、不覆盖已有字段。当前提取学历、明确标注的毕业日期，并在记录完整时推算毕业后有效连续参保起算月和完成月数。不会根据单位名称推断单位合格，也不判断材料真伪、申请人身份、家庭住房或当前参保是否属实。

逐月参保推算须有唯一记录范围，并覆盖毕业当月至参考日期前一个月。缺行不视为未参保；同月状态冲突暂停推算；补缴、欠缴、未缴等会中断连续计数；未完成的当前月份不计入。若毕业日期或参考日期变化，必须重新读取依赖这些日期的材料。该月度计算沿用项目现有规则假设，仍需对照具体政策口径。

样例明确带“合成演示材料”标识，无真实身份号码：正常记录推算为 15 个月，带 2026 年 8 月欠缴的样例推算为 1 个月。两份 PDF 已渲染检查中文、页数与文本提取。

文件不上传外部服务、不发送给大模型，也不写入政策数据库。PDF/TXT 在本机内存中读取；可选图片读取使用临时文件并在结束后清除。页面内存保留当前提取结果，清空申请信息会一并清空材料状态。

## 可选材料环境

本机已在工作目录独立材料环境验证 pypdf 6.10.0。源码移到其他电脑后，TXT 仍可使用；文字 PDF 可以按下面方式安装到项目自己的环境：

```powershell
python -m venv .venv-documents
.venv-documents\Scripts\python.exe -m pip install -r requirements-documents.txt
```

应用自动检测该环境，也支持通过环境变量 `HCT_DOCUMENT_PYTHON` 指定 Python 可执行文件的绝对路径。它与训练环境分离，不需要 CUDA。

单文件不超过 2MB，PDF 不超过 5 页、提取文字不超过 30000 字。加密 PDF、扫描 PDF 的自动栅格化未实现。可选 Windows 图片 OCR 受本机中文识别组件及脚本执行策略影响；**当前机器脚本执行被系统策略禁止，图片 OCR 不可用，未改动系统策略。** 页面据此只启用文字 PDF/TXT，不能宣称已验证图片识别。

## 人工复核工作台

内置 36 条合成人物草稿，基于当前三项事项，`expected` 全部留空，初始已复核数为 0。草稿不是人工基准，也不是真实申请人样本。它没有扩大官方文件数量。

请先阅读官方原文，再选择结论、引用、缺失字段和准备信息，填写判断依据与复核者标识，最后点击确认。草稿编辑在页面内存中保留；修改已确认内容后会恢复为待复核。导出已复核标注前，服务检查：

- 状态、复核者和带时区的复核时间已填写。
- 编号唯一、字段结构与引用编号有效。
- 标注所依据的政策快照与当前来源一致。

这些检查不能证明标注内容正确或复核者身份。建议由独立复核者审查标注质量，扩充独立原始政策文件后，再建立正式测试集。请将“所列指南范围内条件初筛”与“现行政策完整资格／获批”区分；不确定之处记录在依据中。不要为了与程序答案一致修改人工判断。

可导入已复核标注继续工作。页面不持久保存标注，关闭前请下载草稿或导出已复核记录。

## 独立评测入口

对用户实际导出的已复核记录验证并生成预测任务：

```powershell
python -m training.review_benchmark --annotations 已复核标注.json --export-tasks data/reviewed_benchmark.jsonl --output training-runs/manual-validation.json
python -m training.predict --data data/reviewed_benchmark.jsonl --model 本地基础模型目录 --adapter checkpoints/grpo --evidence-mode retrieval --output training-runs/manual-predictions.jsonl
python -m training.review_benchmark --annotations 已复核标注.json --predictions training-runs/manual-predictions.jsonl --output training-runs/manual-evaluation.json
```

待复核草稿会被拒绝，不能当作人工标签计算准确率。该数据默认不进入训练；正式对照需要重新划分训练／开发／测试和政策文件族，避免把已经查看的旧留出样本当作全新测试。

- 浏览器验证了材料默认不勾选、确认填入、参保中断样例、0/36 待审状态，以及真实模型检索记录和冲突提示。
