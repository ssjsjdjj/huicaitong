## 实验目标

验证给定相同证据时，GRPO 是否在 SFT 基础上提升结构化核验质量。模型需抽取自然语言条件、识别缺失信息并选择支持结论的证据；确定性规则可以作为参考与独立基线。

对照至少包括基础指令模型 + RAG、SFT + RAG、SFT + GRPO + RAG、RAG + 显式规则。固定检索器、模型规模、提示模板、测试文档与生成预算，保存代码版本、模型版本、数据散列和运行配置。

## 数据

开发数据是合成弱监督，不能以规则生成标签再评价相同规则的方式宣称政策准确率。当前数据按来源族留出租房资料，仍只有很少文件，结论适用范围有限。

正式数据应覆盖多份独立政策与版本，包含条件满足、明确不满足、缺失信息、超出覆盖范围、新旧冲突、跨文档条件等。按人物组排除重复改写，按文件族或版本划分训练与测试，由至少两名复核者核对结论和条款，记录分歧处理。

## 指标

- 结论准确率与逐类召回率，避免大量“不符合”掩盖正例质量。
- 引用精确率／召回率，以及独立人工抽检的条款支持率；编号存在不等于结论有证据。
- 缺失字段 F1、材料清单 F1 与材料遗漏率。
- 有效 JSON 比例、响应耗时、输出 token、峰值显存与完整失败数量。
- 对同一测试集保留全部预测；超时、格式错和空输出都计入，不删除失败样本。

## 奖励与消融

当前示例奖励：格式有效 0.05；结论正确后再计入 0.55 正确性、0.20 引用 F1、0.10 缺失信息 F1、0.10 材料 F1。虚构或重复引用得零分。解释文本不自动按“语言漂亮”加分。

后续消融可分别移除引用奖励、缺失字段奖励、版本过滤，观察对应错误类型。奖励权重仅作为开发起点，不能在测试集上反复调到最好。观察奖励分布和组内差异，避免所有候选同分导致没有有效学习信号。

## 本届演示建议

演示已就业硕士、在读学生、住房冲突、社保起算晚、境外学历五类案例；展示初筛 → 条件 → 证据 → 来源 → 报告导出。当前模型为初始实验版，界面保留规则与模型差异提示。以真实运行日志和独立人工评测补充后续材料。
