## 日期与社保建模约定

- 申请日期由用户明确选择；默认重现 2026-10-21 这次开发快照，不读取主机时区冒充真实申请时间。
- 社保起算输入为月份，要求填入毕业当月或以后的有效连续起算月；不含毕业前非毕业当月的月份。
- 连续完成月数由用户提供，且不能超过截至申请月份可完成的数量。应用不查询社保系统，不判断补缴事实。
- 六个月完成时间按第六个月月末计算，首笔生活补贴可申领月份从其后一个月开始。政策日期边界仍需人工核实。
- 所有结论都是已编码条件的参考初筛，不能作为发放或审批决定。
