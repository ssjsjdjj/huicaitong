连接模型

连接你自己的本地模型

当前规则基线可直接使用。模型接入后，其结果会单独显示，便于对照。

1. 启动支持 chat-completions 接口的本地模型服务。

2. 在项目根目录创建 .env.local，参考 .env.example：

HCT_LLM_BASE_URL=http://127.0.0.1:11434/v1
HCT_LLM_MODEL=你的本地模型名称

3. 重启本应用。模型核验按钮会在检测到配置后启用。

不会通过网页收集 API 密钥。配置模型不代表它已完成 SFT 或 GRPO 训练；训练步骤请查看项目 README。
